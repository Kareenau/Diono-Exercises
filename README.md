 Exercises
Exercise 1 — Medical & Travel Expense Request

The first exercise implements a web page for displaying and managing medical and travel expense information.



* Dynamic data loading using JSON
* HTML, CSS and JavaScript implementation
* Multiple datasets
* Dynamic table/content rendering
* WCB branding and logo

 Exercise 2 — Workers Progress Report

The second exercise implements a web page for displaying workers' progress report information.



* Dynamic data loading from JSON files
* Structured worker and treatment data
* Dynamic content rendering using JavaScript
* Responsive and organized UI
* WCB branding

 Data Handling

The exercises use JSON files as datasets. JavaScript loads the data dynamically and uses it to populate the web pages instead of hard-coding all information directly into the HTML.

The repository also contains demonstration videos for the completed exercises:

* `medical-travel-request.mp4`
* `workers-progress-report.mp4`

 Howto Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the required exercise folder (`diano1` or `diano2`).
4. Run the HTML file using a local development server such as **Live Server**.
5. Interact with the webpage and switch between the available datasets where applicable.
